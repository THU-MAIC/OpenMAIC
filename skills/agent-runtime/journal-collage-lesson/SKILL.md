# 手账拼贴风讲解课

先加载 `/stage-design`，按它的流程建课、写 roster、逐页 `generate_scene`、最后 `generate_tts`；本 Skill 只规定这一段讲解的结构、视觉和讲稿。在 OpenMAIC 里，「讲稿」就是每页的旁白：按页内的块拆成短段，配聚光灯或激光笔指向对应的元素。已有本风格的 .pptx 时走 `/pptx-import`；要补页时按 `/page-clone` 用 `duplicate_scene` 复制相邻页再只换字；页面元素的写法以 `/slide-craft` 为准；有 `render_scene_preview` 时，交付前逐页渲染检查。

## 什么时候用

- 一节课里专门讲清**一个核心概念**的那一段：3–5 分钟，约 6 页幻灯片，画面是一本贴满便利贴、胶带和荧光笔的手账，每页配一段讲稿。
- 讲完以后学员带着正确的理解进入下一个环节，并在那里认出手账里记过的东西。
- 不限学科。AI、历史、语文、生物、物理、通识都能用；只要这一段的任务是「讲透一个道理」，不是「练会一个动作」。
- 不适用于：整节课的完整课程设计、纯操作实训、习题讲评课、整本书导读。这里只负责概念讲解那一段。

气质是「一起记笔记」：不是老师在台上讲，而是老师翻开自己的本子给你看。适合需要亲切感、生活气的话题，也适合把零散现象收拢成一个道理。

## 一、开工前先弄清楚五件事

1. **核心理解**：一句话，学员学完必须带走的那条道理。
2. **讲完之后学员去做什么，以及这一节怎么收尾**：练习、实验、讨论、作业、工作台、还是下一节课。必须二选一定下来——**开放型**（后面有承接环节，讲解为下一步铺路）还是**封闭型**（这节自己收口，后面没有承接环节）。它决定第 6 页「待办」长什么样；不问清，就会做出一页把人往空处引的结尾。
3. **要落到的知识点**：本节涉及的术语、概念、公式、原理，最多四个（连线页右边正好放四张术语卡）。
4. **课程里真实存在的设定**：用到的案例、作品、人物，课程里是否真的存在。不要发明课程里没有的角色、昵称或情节。
5. **有没有现成的「翻车现场」**：真实的错误回答、失败记录、学员常见的错法。有就做第 2 页剪报；没有就去掉，改成 5 页。

缺任何一样，先问，不要猜。第 2 项默认要问，用户说「随便」时，按「后面到底有没有练习或项目」自己判断，并在交付时说明选了哪种。

## 二、结构：首页、剪报、道理、拍立得、连线、待办

总时长 3–5 分钟，讲稿合计 1000–1500 字。默认 6 页：

| 页 | 环节 | 时长 | 做什么 |
|---|---|---|---|
| 1 | 首页 | 约 30 秒 | 手账首页：课程名、标题（关键词用荧光笔标出）、一张粉色便利贴写「今天的问题」 |
| 2 | 剪报 | 约 30 秒 | 贴一张「翻车现场」：对话截图式纸片或剪报，旁边手写红笔批注，点出毛病 |
| 3 | 道理 | 约 60 秒 | 两张纸片并排对照（之前 vs 之后、错的 vs 对的），关键差别用荧光笔标出，让学员自己找 |
| 4 | 拍立得 | 约 75 秒 | 生活场景类比，四张拍立得或便利贴排成一行：第 1 张是问题，后三张各是一条规矩 |
| 5 | 连线 | 约 60 秒 | 左边四张类比便利贴，右边本学科术语卡，手绘虚线一一连起来 |
| 6 | 待办 | 约 30 秒 | 待办清单：三个检查问题，手画方框，不打勾 |

规则：

- **一个类比只占一页。** 类比讲久了学员跟不上，不要用同一个场景撑好几页。
- **拍立得四张和连线页一一对应。** 第 4 页每一张的规矩，第 5 页都要有对应的术语或原理。
- **后续环节的答案不进幻灯片。** 后面有练习题、实验结论或讨论题时，把题目化成待办清单上的问题，只提问、不给答案；必要时用结构相同的类比把思路铺好。
- **剪报页可选。** 没有现成的翻车现场，就去掉，改成 5 页。
- **页数可以伸缩，环节顺序不变。** 知识点少时可以把「连线」并入「道理」页（右边直接贴术语卡），或去掉剪报；但**不许把「拍立得」拆成两页**，也不许把「待办」提前。
- **默认六页的节奏不要拉长**：一页只说一件事，宁可少讲，不要在一页上塞两组对照。

### 第 6 页「待办」的两种收尾

先问用户这门课后面还有没有承接环节，再决定第 6 页怎么收。

**开放型（后面有练习、实验、工作台或 PBL）**

- 三个检查问题，每个都指向下一步要做的那个决定，只提问、不给答案。
- 方框一律不勾，视觉上就是「等你回来打勾」。
- 末尾一句把人交出去：「接下来进练习／进工作台」，并说清下一步要交付什么。
- 讲稿结尾补一句「哪个问题答不上来，回第 N 页看那张纸片」，给学员一条回头的路。
- 封面上那张粉色便利贴在这里回收一次。

**封闭型（这节讲完就结束，后面没有承接环节）**

- 仍然是待办清单，但三个问题改成「合上本子之前，自己得答得出的三件事」，答案都在第 3 页道理里，不是新问题。
- 不提「工作台」「项目」这类词——那会把人引到一个不存在的地方。
- 底部手写结论换成一句「它管用到哪儿、不管用到哪儿」（借用第三节的类比边界）。
- 讲稿最后一句是「讲到这儿，这一节就完了」，而不是「接下来我们去……」。
- 封面那张粉色便利贴仍然要回收：在这里回答它，然后收笔。

两种收尾都不许在幻灯片上写出后续环节的答案；区别只在「往下一步交棒」还是「就地合上」。

各学科示例（只是示例，按实际主题重选）：

| 学科 | 核心理解 | 拍立得场景 |
|---|---|---|
| AI | 模型每一步按概率抽下一个词，所以同一个问题会得到不同回答 | 奶茶店点单：同一句「随便」，店员每次推荐的不一样 |
| 历史 | 史料有立场，要交叉印证 | 几个邻居各自讲同一场争吵 |
| 语文 | 同一个词在不同语境里意思不同 | 同一句「你可真行」，四个场合四种语气 |
| 生物 | 酶只催化与它形状匹配的反应 | 钥匙和锁、配钥匙的小店 |
| 物理 | 合力为零时，运动状态不变 | 冰面上推箱子、拔河打平 |

## 三、内容的严谨性

手账可以随意，说法必须准确。

- **主语要准。** 说清到底是谁、是哪一部分在起作用，不要用一个笼统的大词代替。
- **不要说过头。** 结论只说到证据支持的范围。比如「按概率抽词」不要说成「AI 在自由发挥」。
- **示意数字标明示意。** 便利贴上写的分数、百分比、概率格子如果是编的，讲稿里必须明说「这是示意」。
- **类比要标边界。** 类比里成立、在本学科里不成立的地方，讲稿里点一句（比如「店员没有记忆，模型却有上下文」）。
- **区分「看起来对」和「确实对」。** 结尾提醒学员用证据检验，不要凭结果像不像来判断。

## 四、页面文字

- **标题**：页面左上，粗黑体一句话（40–44px；封面 52–60px 可折两行），不超过 20 字。全课用同一种句式（例如都用「……为什么会……」「……，到底看什么」），不要一页疑问句一页名词短语。
- **荧光笔**：每页最多标一处，标的就是这页要带走的那个词。多了就等于没标。
- **便利贴**：一张一件事。标题一个词，正文不超过 16 字。
- **红笔批注**：只用在出错、要注意的地方，一句话，结尾可以有一个箭头 →。
- **底部手写结论**：每页一句，红笔，下面一道虚线，不超过 24 字。
- **页面上写过的，讲稿里不再念。** 不重复，只补解释：为什么、容易栽在哪、下一步去哪。
- 术语卡、纸片上的字同样受字数限制：术语卡只写术语本身（可带一个两字的限定），纸片只写它要对照的那句话。

## 五、视觉规范

画布 16:9，按 1920×1080 设计。

**字体**

- 全篇用**站酷快乐体**（ZCOOL KuaiLe）。只有一种字重，不要加粗。
- 长段说明读起来吃力时，可以改用思源黑体（Noto Sans SC）常规字重。
- 英文单词、代码直接用站酷快乐体或等宽字体。

**颜色**

| 用途 | 色值 |
|---|---|
| 背景（横线纸） | `#FBF6EA`，每 56px 一道 2px 横线 `#E9DDC2` |
| 左侧装订红线 | `#E8A0A0`，4px，距左 200px |
| 墨水、正文 | `#2A2522` |
| 次要文字（小标题、日期） | `#7A6A5A` |
| 荧光笔 | `#FFE066`，实心、不透明度 90–95%，只盖住文字下半截（字号的 45–55%），且必须压在文字元素**下面** |
| 便利贴 | 黄 `#FFF3A8`、粉 `#FFD6DE`、蓝 `#D9ECFF` |
| 胶带（85% 不透明） | 蓝 `#9FD8E8`、绿 `#C9E6B6`、橘 `#F7B7A3` |
| 红笔、出错 | `#C2272D` |
| 正确、做得好 | `#3D7A3A` |
| 拍立得白卡 | `#FFFEFA`，2px 边 `#E2D8C3` |

**版式元素**

- **横线纸**：作为整页底色，横线间距 56px、2px；正文尽量压在横线上，压不住也不算错，但不要故意错位半行。
- **便利贴**：无边框，右下 4–6px 实心浅色投影（同色系加深），旋转 -3° 到 3° 之间，每张角度不同。
- **胶带**：46px 高、150–260px 长的半透明色条，压在便利贴或拍立得的上边缘，旋转 ±4–8°。**胶带必须写在被贴的东西之后**（元素顺序在后），才能盖在上面，而不是被压在底下。
- **拍立得**：白卡、下边留宽白；卡内按三件套排（小标题 + 大字 + 一行注解），需要时在大字旁补一幅极简线稿，旋转约 4°。
- **印章**：红色圆圈 6px 边，里面两行字，旋转约 12°，每课最多一个，只放在封面。
- **虚线贴纸**：4px 墨色虚线边、24px 圆角，用来表示「被切开、被贴上去」的东西（剪报纸片、对话截图式纸片）。
- **连线**：手绘虚线箭头，墨色；连线页的每条线都要能看清起止点，不要穿过字。
- **每张便利贴、每张拍立得都是独立元素**，方便讲课时用聚光灯逐张点亮；不要把它们焊成一张大图。
### 视觉重心：一页得有一个「大东西」

手账「平」的原因几乎只有一个：所有字差不多大。下面这套层级是硬性要求。

| 角色 | 字号（画布宽 1000） | 字重 | 用在哪 |
|---|---|---|---|
| 页标题 | 40–44；封面 52–60，可折两行 | 粗黑 | 页面左上，一句话 |
| 卡内大字 | 56–70 | 常规 | 拍立得/便利贴中央，写「数字 + 单位」：`2 圈`、`2 间`、`1 门`、`3 倍` |
| 卡内小标题 | 17–18 | 粗 | 大字上方，一个词 |
| 卡内注解 | 15 | 常规 | 大字下方一行，≤12 字 |
| 重点句 | 22 | 粗 | 纸片里要被记住的那句 |
| 纸片正文 | 16–20 | 常规 | 道理页两张纸片 |
| 底部结论 | 24–26 | 粗·红笔 | 每页最后一行 |

- **一页至少有一处字号差 ×3。** 60px 的大字配 15px 的注解，眼睛才知道先看哪儿；整页都是 16–20px，读者不知道从哪读起。
- **标题用粗黑，不用手写体。** 多数环境没有站酷快乐体，手写出不来会掉成常规黑体，反而最没气势；粗黑标题在任何环境都立得住。手写体只留给便条、注解和大数字。
- **拍立得四张写成三件套**：一个小标题 + 一个大字 + 一行注解。大字里的数字必须是本节真要记住的量；编的数字在讲稿里说明是示意。
- **荧光笔必须压在文字下面。** 它是一块独立色块，元素顺序要排在它标的文字**之前**（先放色块，再把文字压上来）。排在后面会把字染灰、看着像褪色；只改位置解决不了遮挡，要新加一块插到文字索引之前，再删掉旧的。参数：实心 `#FFE066`、不透明度 90–95%、高度约字号的 45–55%、正好落在字的下半截、左右各出字 4–8 px、倾角 -1°。
- **结论行以 `→` 开头**，红笔 24–26px，一行说完；分隔线用点线（dotted），虚线留给剪报纸片和连线。
- **封面左上先交代出处**：《课程名》· 手账讲解 · 共 N 页；印章写动词短句（「今天开工！」），不写编号。
- 内容集中在页面上 2/3，结论落在下 1/4，中间留空——手账怕的不是空，是满。
- 不加装饰条（无色块页眉、无渐变、无图标条），一页最多三种胶带颜色。

**人物与道具**

- 拍立得里放简笔画：圆角头、点眼、弯嘴，线条 5px 墨色，填便利贴色。
- 道具也画成简笔：纸条、杯子、书、门。
- **不要画真人、明星、影视角色或品牌形象**，也不要贴真实照片截图冒充原图。做一个「对话截图式纸片」时，用纸片 + 手写体假对话，不要真的截图。

## 六、讲稿

讲稿要像老师翻着自己的手账给你讲，语气比讲台上松一点。讲稿单独成一份文档，按页分节。

- **每页开头先写一行【屏幕替你说了：……】**，列出屏幕上已经有、不用念的内容。正文只讲屏幕上没有的三样：为什么、容易栽在哪、下一步去哪。
- **用口语。** 短句。用「你」「咱们」，不用「同学们」，不用「首先／其次／综上所述」。可以自嘲，可以「记一笔」「我上次就栽在这儿」。
- **留出互动。** 括号标动作提示，不念出来：`（停三秒，让大家找荧光笔标的那个词）`、`（指粉色便利贴）`、`（指第 2 张拍立得）`。
- **拍立得页先交代结构。** 「第 1 张是问题，后面三张各是一条规矩」，每张按「报名字 → 讲道理 → 落回本学科」三步讲，不要跳步。
- **埋一条暗线。** 让一样东西贯穿：封面那张粉色便利贴，在道理页被荧光笔标出答案的关键，在待办页再回到它。
- **示意与边界明说。** 便利贴上的数字是示意、类比在哪一步不成立，都在这一页讲稿里点一句。
- **结尾不总结全课**：开放型把人送进下一步的三个待办问题；封闭型就地合上，只留一句他能自己复述的结论。
- **一句一句对着画面写。** 讲稿拆成短段，一段对应页面上的一块（一张纸片、一张拍立得、一张术语卡），念完正好落在那一块上。
- **字数控制**：全篇 1000–1500 字，单页讲稿不超过约 260 字；超了宁可删形容词，不要加快语速。

## 七、把它落进课堂

- **已有这套手账风格的 .pptx 时：先原版导入，不重绘。** 导入后一页都不要重排、改色、换字体；只修那一处真问题（文字出框、删不掉的空框、乱码标题）。
- **要补页或补互动时：复制相邻的原页 → 只换字。** 纸底色、便利贴圆角与投影、胶带角度全部继承，读者看不出是后补的；复制出来的新页记得检查胶带是否还在便利贴上面。
- **没有原件、要从零做页时**：按第五节的色值、版式元素、人物规范自己搭，页页保持同一本草稿本的样子（同一张横线纸、同一条装订红线的位置）。
- **讲稿进旁白**：按页内的「块」把讲稿拆成 3–6 段短句挂在对应画面上（聚光灯指向那一块），不要整页一段念到底；屏幕上的字不进旁白。
- **改过讲稿的页面必须重新生成语音**，否则是哑页。
- **交付前逐页渲染出来看**：标题不折行；便利贴文字不溢出；胶带盖在便利贴上面；荧光笔只盖下半截且每页一处；连线不穿字；底部结论不压住纸片。

## 八、交付前自查

- [ ] 核心理解在道理页讲透了，主语、范围都对。
- [ ] 拍立得只占一页；四张和连线页一一对应。
- [ ] 后续环节的答案没有出现在幻灯片上。
- [ ] 没有课程里不存在的角色名或设定。

## 九、例外

- 课程本身已有另一套视觉体系（浅色极简课件、漫画风等）且用户要求保持一致时，视觉规范让位给原课件，只借用「六环节结构 + 荧光笔一处 + 一张便利贴埋暗线 + 讲稿拆块」的做法。
- 用户给了逐字稿或指定原话，就保留其事实与顺序，只压缩句式、拆分段，不重写内容。
- 用户明确要求「不要翻车现场」或没有真实错例时，去掉剪报页，5 页，其余顺序不变；不要为了凑页数编一个错误回答。
- 用户没说清后面有没有承接环节时，宁可做成封闭型并说明理由，也不要在结尾凭空许诺一个不存在的下一步。
- 学员是低龄段时，便利贴正文降到 12 字以内，红笔批注改成「注意：……」的写法，不用箭头。

## 附：完整示例（AI 原理 · 同一个问题，为什么两次答得不一样）

核心理解：模型每一步都从一批候选词里按概率抽一个，所以同一个问题两次可能走出不同的回答；「温度」调的是抽得集中还是分散。

1. **首页**：标题「同一个问题，答案为什么会变」，「会变」荧光笔标出。粉色便利贴：「今天的问题：我又没改问题，它怎么换了个说法？」
2. **剪报**：两张对话纸片，同一句「给我的奶茶店起个名字」，两次回答不同。红笔批注：「我没改字啊 →」
3. **道理**：左纸片写「下一个词只有一个答案」（划掉），右纸片画一排候选词和各自的概率小格子，抽中的那个用荧光笔标出。底部：「每一步都在抽签，签筒里不止一支」。
4. **拍立得：奶茶店点单**。第 1 张：两次都说「随便」，店员推荐不一样。第 2 张：店员心里有张「推荐榜」。第 3 张：榜上越靠前越常被推荐，但不是每次都推第一。第 4 张：店长说「今天只推前三」，推荐就稳了。
5. **连线**：随便 → 同一个提示词；推荐榜 → 候选词的概率；不总推第一 → 按概率采样；只推前三 → 调低温度、限制候选范围。
6. **待办**：☐ 你要它稳定，还是要它多给几个点子？☐ 两次答案不同，哪一次是对的，怎么判断？☐ 你能用什么办法让它答得更稳？底部：「答案会变不是坏事，看你要什么」。
