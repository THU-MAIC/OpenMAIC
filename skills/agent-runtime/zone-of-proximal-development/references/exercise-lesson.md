# 整节测验习题课的组织方式

用于创建或完善一节课。它以已有知识的运用、困难修正和独立复核为中心；不是只出题和公布分数，也不是从头讲完一个知识单元。

## 用任务关系组织，不以题量组织

先确定一个核心目标及可观察的成功标准，再分配时间。一个约20分钟的短课可以包含以下六个功能环节，页数随内容与平台能力调整：

| 环节 | 作用与学习者行动 | 设计要点 |
| --- | --- | --- |
| 目标与规则（约1分钟） | 知道练什么、需要留下什么证据 | 说明先独立再借帮助，得分之外也看理由；不要在开场提前讲诊断题的解法 |
| 独立诊断（约3分钟） | 提交当前能做出的答案与关键理由 | 少量有区分意义的任务；无提示、不抢答；没有作答不预填错因 |
| 针对性讲评（约4分钟） | 对照自己的作品，辨析一个关键错误并理解方法 | 解释为何这样做；典型错解标明是示例；不能把整页题解当作对真实学生的诊断 |
| 分层练习（约5分钟） | 按需获得帮助，亲自完成关键动作 | 困难者补先备或用步骤卡；已会者可跳过带练或做可比变化题。路线由谁选择须明确 |
| 新题独立复核（约5分钟） | 不看提示完成新任务，附理由或检查 | 与本课目标一致，避免同时引入新规则；复核先于对该题的讲解 |
| 收束与后续（约2分钟） | 说清本次独立做了什么、借了什么帮助，选择下一步 | 有证据才报告变化；仍困难者回到具体卡点；已完成者给有意义的后续练习，不宣布永久掌握 |

练习时间是设计估计，不是观察到的学习用时。教师主导课可在真实答案返回后调整讲评；一次性生成的课堂则应把讲评、示范与路线选择写为可选择材料，不伪造实时适应。

## 题组和讲评之间的关系

每题先标明用途：诊断、讲评例子、受助练习、独立复核或拓展。不要把所有题都当成可相加的同类成绩。关键变换或论证理由相同、表面数据不同的任务适合第一次撤架；引入新知识的题属于拓展，不混入“已经能独立”的复核证据。

讲评至少处理一个本目标的关键关系，而非只列标准答案。可用“错在哪里—为什么不成立—怎样修正—回到自己的作品检查”组织，但先保留学习者辨析的机会。示范题、受助题与复核题要检查答案交叉泄露，包括题干、选项、旁白和AI同伴发言。

例：若本课练习正整数系数的 ax+b=c，诊断可用3x+5=20，讲评用另一道等式比较“只改一边”与“双方同做运算”，受助练习用4x+3=19，独立复核用5x+4=34。不要在复核之前又讲解5x+4=34，也不要突然改成含分数或负系数方程。其他学科按自己的关键动作设计，不套用方程模板。

## 可执行的练习路线

静态课至少给出两种可实际执行的选择：

- 能独立完成且理由充分：跳过步骤带练，去新题复核；新题遇到困难可返回讲评或帮助页。
- 有明确困难：到对应讲评或受助练习；先备不足时先做更小任务，别连续给更难题。

写清真实导航方法，例如打开页面目录选择相应标题。不要画一个未实现的“自动分层”或“已掌握解锁”按钮；仅有翻页也不证明发生了撤架。页面与题目重排后更新所有路线提示。

若目录缩略图会显示讲评内容，提醒独立作答时先收起目录和帮助，不把可自由翻页的习题课描述成技术上强制无提示的考试。

## 记录与收课

结束页提示学习者回看实际作答，留下“初答—帮助—新题表现—下一步”的简短记录；自报的帮助使用情况注明来自自报。平台不能跨页自动汇总时，让学习者自己填写或把记录带回工作台，不伪造自动生成的学情报告。

quiz的答题记录与生成式interactive页的临时输入可能使用不同保存机制。需要保留退出记录时，优先用已验证可提交的组件；交互页只在当前文档内保存状态时明确提醒另行保留。不要把“重新答题后的高分”直接当作首次独立表现。

## 整课验收

检查真实保存的整课，至少能回答：目标是什么；诊断发现哪类需要；讲评为何能回应它；学习者在哪些地方仍需自己做；谁选择帮助或跳过；复核是否移除关键提示；最后如何据实际表现安排下一步。

实际走一次需要帮助的路线和一次跳过带练的路线，确认独立题提交前不泄露答案、跳转指引正确、帮助页可操作、需要记录的回答可取回。分别报告内容保存、功能检查、音频与学生学习成效，不用其中一项替代其他项。
