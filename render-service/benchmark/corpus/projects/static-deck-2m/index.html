Systems lesson

Observe before changing the system

Start with a stable description of inputs, boundaries, and expected outcomes.

01 / 08
Step one

Define a measurable question

A useful question names the condition, the operation, and the signal that confirms success.

02 / 08
Step two

Reduce hidden variables

Freeze configuration and inputs so repeated observations remain comparable.

03 / 08
Step three

Collect evidence by stage

Separate setup, execution, and finalization instead of relying on one total number.

04 / 08
Step four

Compare like with like

Use the same runtime, worker count, media, and output settings for every trial.

05 / 08
Step five

Inspect representative outputs

Performance is not a pass when frames are blank, media is missing, or timing drifts.

06 / 08
Step six

Report distributions

Median and tail values distinguish typical behavior from costly outliers.

07 / 08
Summary

Reproducibility turns a result into evidence

Keep the input, runtime, command, and machine-readable report together.
