# Issue #1851：轻量模型生成与浏览器回归

当前的坏 shape 恢复策略通过了生成、课堂播放、缩略图和 Pro 编辑入口的回归。真实输出也说明：几何格式校验能阻止坏输入拖垮页面，但不能保证图形可见或教学关系正确。

## 真实模型样本

使用当前环境可调用的轻量/Flash 型号，三个场景各重复两次：勾股定理拼图、椭圆圆弧和连续曲线、细胞膜运输流程。请求进入生产 generation 包的提示词与后处理，不使用强模型兜底。

| 型号 | 成功课件 | 原始 shape 数 | 格式错误 shape | 最终 DSL |
| --- | ---: | ---: | ---: | --- |
| gpt-5.6-luna | 6/6 | 64 | 0 | 全部通过 |
| deepseek-flash | 6/6 | 64 | 1 | 全部通过 |
| gemini-3-flash-preview | 6/6 | 44 | 0 | 全部通过 |
| glm-5.3-flash | 未获得可用课件内容 | — | 无法评估 | 输出预算/调用失败 |

18 张课件共 172 个原始 shape；171 个保留为 shape，1 个被移除。没有发现合法路径因验证器误判而丢失，浏览器也未报告非法 SVG 或非有限变换。

DeepSeek 的 `arcs-curves-2` 将 `sine_curve.viewBox` 写成 `[0,0,320,160]`，混淆了 SVG 原生四项 viewBox 和本项目的两项坐标尺寸。DSL normalizer 在几何验证前拒绝该格式，转入统一恢复函数。该 shape 没有内嵌标签，因此恢复结果为 null；邻近独立 text、坐标轴和其他元素继续渲染。以原始坏 shape 回放历史记录，也不会影响整页。

Luna 使用 8,192 输出 token。DeepSeek 使用 32,768，部分请求有大量 reasoning token。Gemini 使用 16,384，并在该批请求携带 `thinking: {type: 'disabled'}`；这只是请求参数，不代表网关实际关闭了思考。这些样本用于正确性回归，不能直接比较模型速度、价格或能力。

GLM 的两个 8,192-token 请求均耗尽预算，只有 reasoning、没有最终课件内容；32,768-token 的首张请求超过 300 秒。再尝试关闭思考模式后，首张仍消耗 16,384 reasoning token 被截断，后续返回 HTTP 400（业务代码 400001/1210）。这些失败发生在可用课件输出之前，不能记作 SVG 验证失败。旧 GLM 小型号探测也未返回可用内容。

## 浏览器与真实课堂

Chromium 检查了 31 个对照页面：18 个真实模型样本和 13 个受控故障。受控故障中新生成与历史记录的文本数量、内容、样式一致；固定到相同屏幕位置后，fallback 截图逐字节一致。

独立测试数据库中的课堂课程覆盖 25 个场景：18 个生成结果、1 个真实坏 shape 的历史回放、6 个生成/历史故障对照。切页、缩略图、刷新及 Pro 进出均通过，浏览器异常为 0。历史数据仍存为 shape，新生成的坏 shape 在有文字时存为 text；渲染结果一致。此项检查不包含语音合成。

回归发现并修复了旧 Pro ShapeElement 的遗漏：它仍直接渲染无效 path，导致深色背景消失、白色标签难以看见。现在它使用同一个 shapeToTextFallback 和 SDK BaseTextElement，保留标签编辑与原 shape 的选中/更新关系。新增组件回归测试覆盖坏图、深底白字、旋转、底部对齐、合法/非法几何切换和无标签移除。相关 12 个测试、TypeScript 和定向 ESLint 均通过。

另外通过 `/api/generation-runs` 对 Luna 发起真实服务端生成，覆盖 outline → agents → slide content → actions → 持久化 → 课堂展示。结果另存于 `results/live-api/`。

## 生成效果的边界

- Luna 的第一张面积拼图包含非直角三角形、形状遮挡和标签重叠。路径语法合法，但不能作为正确的勾股定理证明图。
- DeepSeek 和 Gemini 的部分开放圆弧/曲线使用 `stroke` / `strokeWidth`，而项目需要 `outline`。在透明填充下没有可用描边，曲线不可见；这不触发几何格式验证。这类问题适合单独做样式 schema 修复或生成质量检查。
- 无标签坏图被移除能保住课堂，但会损失原本要讲解的图形。现有旁边的独立文字不会自动并入 fallback，也不会删除。
- 故障矩阵验证了有标签坏图的可靠恢复；本轮自然产生的唯一坏图没有标签，没有自然出现的有标签坏图样本。
