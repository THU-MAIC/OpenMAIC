個人用の OpenMAIC で ChatGPT にサインインすると、プランの利用枠で授業を生成できます。この連携は現在プレビュー版です。

## 利用条件

PostgreSQL とインスタンスの秘密鍵を用意し、サーバーに `OWNER_SINGLE_USER=true` と `OPENMAIC_CHATGPT_PLAN_ENABLED=true` を設定します。認証方式を登録する場合は `singleUser` のみ使用できます。`ACCESS_CODE` を知っている人など、この環境にアクセスできる人は全員、接続したアカウントの利用枠を使用できます。

## アカウントを接続する

モデル設定のチャットサービスで **ChatGPT プラン** を選び、説明を確認して ChatGPT でサインインします。新しいタブで OpenMAIC にプランの使用を許可します。初回の接続後に表示される確認画面で使用状況を確認し、画面を閉じます。アカウントで利用できるモデルを授業の各段階に割り当てます。モデル一覧は設定から更新できます。

## 別の端末からサインインする

承認後、別の端末ではコールバックページを開けないことがあります。アドレスバーの `http://127.0.0.1:<port>/auth/callback` から始まる URL をクエリも含めてコピーし、モデル設定に貼り付けてください。URL は 10 分間有効で、一度だけ使用できます。

## 利用枠と接続解除

リクエストは OpenMAIC に許可された利用枠を消費します。上限に達するとリクエストは停止し、別のプロバイダーを手動で選択できます。[ChatGPT の使用状況](https://chatgpt.com/settings/usage)から利用枠を確認・管理できます。接続を解除すると、暗号化された認証情報がサーバーから削除され、OpenAI に失効を要求します。失効を確認できない場合は ChatGPT の設定から OpenMAIC を解除できます。

接続を解除しても、次回のサインインに使う登録情報は保持されます。ChatGPT のアカウントやワークスペースを変更するには、接続を解除し、「別のアカウントを使用」を選んで確認します。再度サインインし、使用するアカウントとワークスペースを選んでください。環境のホスト ID は引き継がれます。
