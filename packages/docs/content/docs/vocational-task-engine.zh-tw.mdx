title: 職教任務引擎
description: 為職業教育實作任務生成包含操作訓練和決策回饋的互動課堂。
---

職教任務引擎是面向實作訓練的實驗功能。它會把真實或模擬工作任務整理成包含任務簡報、操作練習、流程圖和可玩挑戰的混合課堂。

## 適用任務

適合包含工具、設備、材料、狀態變化、安全邊界、品質檢查或 GO/STOP 判斷的任務，例如電池包更換前確認、配電櫃送電前檢查、輸液設定或焊接設備檢查。

純理論主題會回退到一般 OpenMAIC 課堂。

## 生成職教課堂

1. 在首頁輸入具體職教任務。
2. 開啟輸入框下方的**測試功能 · 職教任務**。
3. 可選：同時開啟**本地知識庫**。
4. 開始生成。

職教開關會自動開啟 Interactive Mode，並選擇職教專用規劃器。

## 課堂結構

適合的任務通常生成 10–14 個場景：

| 類別 | 常見數量 | 用途 |
| --- | --- | --- |
| 簡報和講解 | `2`–`4` | 任務目標、風險邊界和判斷依據。 |
| 實作訓練 | `5`–`7` | 步驟、檢查、測量和確認。 |
| 可玩挑戰 | `2`–`4` | GO/STOP、排序、風險辨識和故障處理。 |

## procedural-skill 元件

`procedural-skill` 元件提供任務區、工具材料、操作步驟、進度、錯誤回饋、完成標準、重置功能和教師引導。視覺形式會依任務變化，例如檢查工位、測量站、控制面板或 GO/STOP 決策站。

## 與一般互動模式隔離

`procedural-skill` 只允許在職教模式使用。一般 Interactive Mode 如果誤產生該類型，系統會轉成流程圖。

## 與本地知識庫聯用

技術實訓建議同時開啟兩個功能。確認後的材料片段會進入職教大綱、實作元件和教師動作。
