title: 職業訓練タスクエンジン
description: 手順型の職業訓練タスク向けに操作練習と判断フィードバックを生成します。
---

職業訓練タスクエンジンは、実務または模擬作業をブリーフィング、操作練習、図解、プレイ可能な課題を含む授業に変換する実験機能です。

## 適したタスク

工具、設備、材料、状態変化、安全境界、品質確認、GO/STOP 判断を含む作業に向いています。例として、バッテリーパック交換前確認、配電盤通電前点検、輸液設定、溶接設備点検があります。

理論だけの話題は通常の OpenMAIC 授業にフォールバックします。

## 生成手順

1. ホームの入力欄に具体的な作業を記述します。
2. 入力欄の下にある **Experimental · Vocational Task** を有効にします。
3. 必要に応じて **Local Knowledge Base** も有効にします。
4. 生成を開始します。

## 授業構造

適切なタスクでは通常 10–14 シーンが生成されます。

| 種類 | 目安 | 用途 |
| --- | --- | --- |
| ブリーフィングと説明 | `2`–`4` | 目的、危険境界、判断基準。 |
| 手順練習 | `5`–`7` | 操作、点検、測定、確認。 |
| プレイ可能な課題 | `2`–`4` | GO/STOP、並べ替え、危険識別、トラブル対応。 |

## procedural-skill ウィジェット

`procedural-skill` は、作業領域、工具、順序付きステップ、進捗、誤操作フィードバック、完了条件、リセット、教師ガイドを提供します。

このウィジェットは職業訓練モード専用です。通常の Interactive Mode で誤って要求された場合は工程図に変換されます。

## RAG との併用

技術訓練では両方を有効にしてください。確認済みの抜粋がアウトライン、手順ウィジェット、教師アクションに渡されます。
