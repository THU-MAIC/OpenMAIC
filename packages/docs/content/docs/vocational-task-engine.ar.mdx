محرك المهام المهنية وضع تجريبي للتدريب العملي. يحول مهمة عمل حقيقية أو محاكاة إلى صف مختلط يحتوي على شرح تمهيدي وتدريب إجرائي ورسوم توضيحية وتحديات قابلة للعب.

## المهام المناسبة

استخدمه للمهام التي تحتوي على أدوات أو معدات أو مواد أو تغيرات حالة أو حدود سلامة أو فحوص جودة أو قرارات GO/STOP. أما الموضوعات النظرية فتعود تلقائيا إلى صفوف OpenMAIC العادية.

## إنشاء صف مهني

1. اكتب مهمة عمل محددة في الصفحة الرئيسية.
2. فعّل **Experimental · Vocational Task** أسفل مربع الإدخال.
3. فعّل **Local Knowledge Base** عند الحاجة.
4. ابدأ الإنشاء.

## بنية الصف

تنتج المهام المناسبة عادة 10–14 مشهدا:

| الفئة | العدد المعتاد | الغرض |
| --- | --- | --- |
| الشرح التمهيدي | `2`–`4` | الهدف والمخاطر والمعايير وأساس القرار. |
| التدريب الإجرائي | `5`–`7` | الخطوات والفحوص والقياسات والتأكيدات. |
| التحديات | `2`–`4` | GO/STOP والترتيب واكتشاف المخاطر ومعالجة الأعطال. |

## عنصر procedural-skill

يوفر `procedural-skill` منطقة للمهمة والأدوات وخطوات مرتبة وتتبع التقدم وتعليقات للأخطاء ومعايير الإكمال وإعادة ضبط كاملة وإرشادات المعلم.

هذا العنصر مخصص للوضع المهني. إذا طلبه Interactive Mode العادي بالخطأ، يحوله النظام إلى مخطط للعملية.

## الاستخدام مع RAG

للتدريب التقني فعّل الميزتين معا. تمرر مقتطفات المواد المؤكدة إلى المخطط وعناصر التدريب وإجراءات المعلم.
