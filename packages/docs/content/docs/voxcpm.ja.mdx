[VoxCPM2](https://github.com/OpenBMB/VoxCPM) は OpenBMB が公開する音声クローン対応のオープンソース TTS モデルです。OpenMAIC にはアダプターが組み込まれているため、自分の環境で VoxCPM を動かせばすぐに連携できます。

## VoxCPM2 を使うタイミング

- 安定的で無料、文字数課金なしの TTS が欲しいとき。
- 各エージェントに短いサンプル音声から固有の声を持たせる音声クローンを使いたいとき。
- オンプレミスやオフライン環境で運用しているとき。

単にデフォルトの声が欲しいだけなら、組み込みの **Doubao** または **OpenAI 互換** プロバイダーのほうが簡単です。[設定 → TTS プロバイダー](./configuration.mdx#tts-プロバイダー)を参照してください。

## 1. VoxCPM バックエンドを起動する

OpenMAIC は 3 種類のデプロイ形態に対応しています。いずれも同じ OpenMAIC アダプターを使い、実際に動かしている形態は `openmaic.yml` のプロバイダーの `options.backend` で選びます（手順 2）。

| バックエンド    | エンドポイント       | 適用シーン                                      |
| -------------- | ------------------ | ---------------------------------------------- |
| **vLLM-Omni**  | `/v1/audio/speech` | OpenAI 互換の音声エンドポイント。GPU サーバー向け。 |
| **Python API** | `/tts/upload`      | VoxCPM 公式 Python ランタイム（FastAPI ベース）。  |
| **Nano-vLLM**  | `/generate`        | 軽量な Nano-vLLM FastAPI デプロイ、小規模マシン向け。 |

各バックエンドの起動方法は [VoxCPM リポジトリ](https://github.com/OpenBMB/VoxCPM)に記載されています。典型的なローカルでのクイックスタート例：

```bash
# vLLM-Omni の例
pip install vllm
python -m vllm_omni.server --model openbmb/VoxCPM2 --port 8000
# エンドポイントは http://localhost:8000/v1
```

## 2. OpenMAIC から接続する

VoxCPM2 は自分のネットワーク上で動くため、エンドポイントはデプロイ側で設定し、ワークスペースは **設定 → モデルサービス** で追加できません。`openmaic.yml` で宣言し、`options.backend` でバックエンドを選んで `tts` スロットに割り当ててください。API キーは不要です。

```yaml title="openmaic.yml"
providers:
  voxcpm:
    preset: voxcpm-tts
    baseUrl: http://localhost:8000/v1
    options:
      backend: vllm-omni          # vllm-omni（既定）| python-api | nano-vllm

slots:
  tts: voxcpm
```

プロバイダーの `options.backend` は `tts` スロットのすべてのリクエストに適用されます。音声の登録は `vllm-omni` バックエンドでのみ使え、`python-api` と `nano-vllm` では音声プロンプトがリクエストごとに送られます。

`openmaic.yml` がない場合、旧来の変数でエンドポイントは設定できますが、バックエンドは選べません。`python-api` や `nano-vllm` を使うには `openmaic.yml` を使ってください。

```bash
TTS_VOXCPM_BASE_URL=http://localhost:8000/v1
```

プロバイダーはサーバー管理なので、エンドポイントは `ALLOW_LOCAL_NETWORKS` なしでプライベートネットワーク上に置け、ユーザーが上書きすることもできません。

## 3. 音声管理

VoxCPM2 を `tts` スロットに割り当て（手順 2）、**設定 → モデルサービス → 音声合成 → VoxCPM2** を開きます。VoxCPM の音声管理は `tts` スロットが `voxcpm-tts` プロバイダーに解決される場合にだけ表示され、3 種類の音声モードがあります。

### Auto Voice（既定）

OpenMAIC は合成時に各エージェントのペルソナから voice prompt を自動生成します。設定不要で、何も変更しなければこの動作になります。

### Prompt voice（プロンプト音声）

自然言語で声の特徴を記述します。生成した音声は再利用可能で、任意のエージェントに割り当てられます。

> _例：「温かみのある女性教師の声。落ち着いて励ます調子、中音域、明瞭な発音。」_

### Clone voice（クローン音声）

60 秒以下、10 MB 以下の短い参照音声クリップをアップロードするか、ブラウザで録音します。クリップは IndexedDB に保存され、合成時に VoxCPM バックエンドへ送信されます。

## トラブルシューティング

| 症状                                  | 考えられる原因                                                                                              |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| リクエストが 404 を返す | `options.backend` が実際のバックエンドと一致していません。手順 1 のエンドポイント表と照合してください。 |
| 初回のクローンリクエストが約 30 秒止まる | バックエンドのコールドスタートです。以降のクローンはウォームランタイムを再利用します。                       |
| 音声が文の途中で途切れる              | バックエンドの出力トークン制限が原因です。`--max-tokens` または VoxCPM 設定の該当項目を増やしてください。     |
| 401 / 403 エラー                      | キー不要のバックエンドに `TTS_VOXCPM_API_KEY` を設定しています。空にしてください。                           |
