---
title: 职教任务引擎
description: 为职业教育实操任务生成包含操作训练和决策反馈的互动课堂。
---

职教任务引擎是面向实操训练的实验功能。它会把真实或模拟工作任务组织为混合课堂，包含任务简报、操作练习、流程图解和可玩的挑战场景。

## 适用任务

适合包含工具、设备、材料、状态变化、安全边界、质量检查或 GO/STOP 判断的任务。例如：

- 动力电池包更换作业前安全确认。
- 低压配电柜送电前检查。
- 静脉输液身份核验与滴速设置。
- 焊接作业前设备检查。

纯理论知识应继续使用普通课堂生成。任务引擎会先做适配性判断，不适合实操训练时自动回退到普通 OpenMAIC 场景。

## 生成职教课堂

1. 打开课堂生成首页。
2. 在主输入框中描述具体的职教任务。
3. 开启输入框下方的**测试功能 · 职教任务**。
4. 可选：同时开启**本地知识库**，使用手册或标准约束生成。
5. 开始生成。

职教开关会自动开启 Interactive Mode，并选择职教专用的大纲规划器。

## 课堂结构

适合的任务通常生成 10–14 个场景：

| 场景类别 | 常见数量 | 作用 |
| --- | --- | --- |
| 简报和讲解 | `2`–`4` | 任务目标、风险边界、标准和判断依据。 |
| 实操训练 | `5`–`7` | 操作步骤、检查、测量和确认。 |
| 可玩挑战 | `2`–`4` | GO/STOP 决策、步骤排序、风险识别和故障处理。 |

第一个场景固定为任务简报幻灯片，在进入详细操作前说明任务目的、安全边界、训练阶段和完成标准。

## procedural-skill 互动组件

职教模式新增 `procedural-skill` 互动组件，可包含：

- 可见的任务区和工具材料区。
- 带进度的有序操作步骤。
- 测量、判断或工具使用选择。
- 对危险或错误操作的反馈。
- 完成标准和完整重置操作。
- 教师高亮控件、更新组件状态的引导动作。

界面形式会随任务变化，例如检查工位、工单台、流程看板、测量站、控制面板、GO/STOP 决策站或故障排查台。

## 与普通互动模式隔离

`procedural-skill` 只允许在职教模式中使用。普通 Interactive Mode 如果意外生成该类型，系统会将其转换为流程图，避免影响原有课程生成行为。

## 与本地知识库联用

技术实训建议同时开启**职教任务**和**本地知识库**。确认后的片段会进入职教大纲、实操组件和教师动作，使训练流程遵循上传材料。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 没有生成实操训练场景 | 输入可能偏理论。请描述具体工作任务、工具、判断点和完成标准。 |
| 普通互动课程中出现流程图 | `procedural-skill` 只在职教开关开启时可用。 |
| 生成步骤与手册冲突 | 上传手册，同时开启本地知识库，并确认相关片段。 |
| GLM 生成缓慢或结果为空 | 系统会自动关闭 GLM 的 scene-content thinking，降低长输出超时风险。 |
