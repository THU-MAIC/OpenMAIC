OpenMAIC は自分のマシンで動かせる Next.js アプリケーションです。少なくとも 1 つの LLM プロバイダーを設定する必要があります。クラウドのプロバイダーは通常 API key が必要ですが、ローカルの Ollama や Lemonade は API key 不要です。

## 前提条件

- **Node.js** 22.19.0 以上
- **pnpm** 10.28.0（未インストールの場合は `npm install -g pnpm@10.28.0`）
- 少なくとも 1 つの LLM プロバイダーを設定。クラウドのプロバイダーは通常 API key が必要、ローカルの Ollama や Lemonade は API key 不要

## インストール

リポジトリをクローンし、依存関係をインストールします。

```bash
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
pnpm install
```

インストール中にプロジェクトで使う workspace パッケージがビルドされます。初回は少し時間がかかる場合があります。

## 設定

サンプルの環境ファイルをコピーし、少なくとも 1 つの LLM プロバイダーを入力します。

```bash
cp .env.example .env.local
```

次にモデルを設定します。ファイルで設定する最も簡単な方法は、`.env.local` の隣に最小限の `openmaic.yml` を置き、キーを `.env.local` に書くことです。

```bash title=".env.local"
OPENAI_API_KEY=sk-...
```

```yaml title="openmaic.yml"
providers:
  openai:
    preset: openai
    apiKey: ${OPENAI_API_KEY}

slots:
  llm: openai:gpt-5.5
```

`openmaic.example.yml` はこれと同じ出発点で、任意のプロバイダーとスロットがコメントアウトされた状態で含まれています。ファイルを使わない場合も、`DEFAULT_MODEL` でモデルを指定すれば旧来のプロバイダー変数が使えます。

```bash title=".env.local"
ANTHROPIC_API_KEY=sk-ant-...
DEFAULT_MODEL=anthropic:claude-sonnet-4-6
```

どちらも使わない場合は、アプリを起動して **設定 → Token Plan** でプランのキーを、または **設定 → モデルサービス** でサービスのキーを入力してください。`openmaic.yml`、`DEFAULT_MODEL`、そこで設定したサービスのいずれもなければ、モデルは設定されず生成は失敗します。

プロバイダー、画像／動画生成、TTS、ASR、ドキュメント解析、Web 検索、アクセス制御、feature flag の詳細設定は[設定説明](./configuration.mdx)を参照してください。

## 実行

授業は PostgreSQL に保存され、`DATABASE_URL` がないとサーバーは起動を拒否します。まずローカル開発用データベース（Docker 上の独立した PostgreSQL、`127.0.0.1:5432`、このマシン上のすべてのチェックアウトで共有。別のポートは `OPENMAIC_DB_PORT` で指定）を起動し、`.env.local` に `DATABASE_URL` を設定します：

```bash
pnpm db:up
```

```bash title=".env.local"
DATABASE_URL=postgres://openmaic:openmaic-dev@127.0.0.1:5432/openmaic
```

開発サーバーを起動します。

```bash
pnpm dev
```

[http://localhost:3000](http://localhost:3000) を開くと OpenMAIC の授業生成ツールが表示されます。トピックを入力するか学習資料をアップロードし、「生成」をクリックすると、AI 教師が完全なマルチシーン授業を構築します。対応する資料形式は選択したパーサーに依存し、通常は PDF、Office 文書、Markdown／プレーンテキスト、画像、一部の音声・動画を含みます。

## 本番ビルド

```bash
pnpm build
DATABASE_URL=postgres://... pnpm start
```

または Vercel、Docker、自分のサーバーにデプロイ可能です。詳しくは[デプロイガイド](./deployment.mdx)を参照してください。
