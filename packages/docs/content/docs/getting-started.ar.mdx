OpenMAIC هو تطبيق Next.js يمكن تشغيله على جهازك الخاص. تحتاج إلى إعداد مزود LLM واحد على الأقل: عادةً ما تتطلب المزودات السحابية مفتاح API؛ أما Ollama أو Lemonade المحليان فلا يحتاجان إلى مفتاح API.

## المتطلبات المسبقة

- **Node.js** 22.19.0 أو أحدث
- **pnpm** 10.28.0 (إذا لم يكن مثبتًا، نفذ `npm install -g pnpm@10.28.0`)
- إعداد مزود LLM واحد على الأقل؛ عادةً ما تتطلب المزودات السحابية مفتاح API، أما Ollama أو Lemonade المحليان فلا يحتاجان إلى مفتاح API

## التثبيت

استنسخ المستودع وثبّت الاعتماديات:

```bash
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
pnpm install
```

أثناء التثبيت، سيتم بناء حزم workspace اللازمة للمشروع، وقد يستغرق التثبيت الأول بعض الوقت.

## الإعداد

انسخ ملف البيئة النموذجي واملأ بيانات مزود LLM واحد على الأقل:

```bash
cp .env.example .env.local
```

افتح `.env.local` واملأ بيانات المزود الذي لديك مفتاح له. مثال:

```bash title=".env.local"
OPENAI_API_KEY=sk-...
# أو
ANTHROPIC_API_KEY=sk-ant-...
# أو Ollama محلي (لا يحتاج إلى مفتاح)
OLLAMA_BASE_URL=http://localhost:11434/v1
```

للحصول على إعدادات كاملة لمزودات الخدمة، وتوليد الصور/الفيديو، وتحويل النص إلى كلام (TTS)، والتعرف على الكلام (ASR)، وتحليل المستندات، والبحث عبر الإنترنت، والتحكم في الوصول، وعلامات الميزات، راجع [تعليمات الإعداد](./configuration.mdx).

## التشغيل

تُحفظ الدروس في PostgreSQL، ويرفض الخادم البدء بدون `DATABASE_URL`. ابدأ قاعدة بيانات تطوير محلية (PostgreSQL منفصل في Docker على `127.0.0.1:5432`؛ استخدم `OPENMAIC_DB_PORT` لمنفذ آخر) وأزل التعليق عن سطر `DATABASE_URL` المحلي في `.env.local`:

```bash
pnpm db:up
# .env.local
# DATABASE_URL=postgres://openmaic:openmaic-dev@127.0.0.1:5432/openmaic
```

شغّل خادم التطوير:

```bash
pnpm dev
```

افتح [http://localhost:3000](http://localhost:3000)، وسترى منشئ الدروس في OpenMAIC. أدخل موضوعًا أو ارفع مواد تعليمية، ثم اضغط على "Generate". سيقوم المعلم الذكي ببناء درس كامل متعدد المشاهد. تعتمد صيغ المواد المدعومة على المحلل المختار، وتشمل عادةً PDF، ومستندات Office، وMarkdown/نص عادي، وصور، وبعض ملفات الصوت/الفيديو؛ ويعتمد ذلك على دعم المحلل.

## بناء الإنتاج

```bash
pnpm build
DATABASE_URL=postgres://... pnpm start
```

يمكنك أيضًا النشر على Vercel أو Docker أو على خادمك الخاص — راجع [دليل النشر](./deployment.mdx).
