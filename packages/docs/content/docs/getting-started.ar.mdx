OpenMAIC هو تطبيق Next.js يمكن تشغيله على جهازك الخاص. تحتاج إلى إعداد مزود LLM واحد على الأقل: عادةً ما تتطلب المزودات السحابية مفتاح API؛ أما Ollama أو Lemonade المحليان فلا يحتاجان إلى مفتاح API.

## المتطلبات المسبقة

- **Node.js** 22.19.0 أو أحدث
- **pnpm** 10.28.0 (إذا لم يكن مثبتًا، نفذ `npm install -g pnpm@10.28.0`)
- إعداد مزود LLM واحد على الأقل؛ عادةً ما تتطلب المزودات السحابية مفتاح API، أما Ollama أو Lemonade المحليان فلا يحتاجان إلى مفتاح API

## التثبيت

استنسخ المستودع وثبّت الاعتماديات:

```bash
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
pnpm install
```

أثناء التثبيت، سيتم بناء حزم workspace اللازمة للمشروع، وقد يستغرق التثبيت الأول بعض الوقت.

## الإعداد

انسخ ملف البيئة النموذجي واملأ بيانات مزود LLM واحد على الأقل:

```bash
cp .env.example .env.local
```

ثم اضبط نموذجًا. أبسط طريقة بالملفات هي وضع `openmaic.yml` مختصر بجوار `.env.local`، مع كتابة المفتاح في `.env.local`:

```bash title=".env.local"
OPENAI_API_KEY=sk-...
```

```yaml title="openmaic.yml"
providers:
  openai:
    preset: openai
    apiKey: ${OPENAI_API_KEY}

slots:
  llm: openai:gpt-5.5
```

الملف `openmaic.example.yml` هو نقطة البداية نفسها، مع مزودين وخانات اختيارية معلّقة في تعليقات. بدون الملف ما زالت متغيرات المزودين القديمة تعمل ما دام `DEFAULT_MODEL` يسمّي النموذج:

```bash title=".env.local"
ANTHROPIC_API_KEY=sk-ant-...
DEFAULT_MODEL=anthropic:claude-sonnet-4-6
```

للاستغناء عن الاثنين، شغّل التطبيق وأدخل مفتاح خطة في **الإعدادات ← Token Plan** أو مفتاح خدمة في **الإعدادات ← خدمات النماذج**. بدون `openmaic.yml` أو `DEFAULT_MODEL` أو خدمة معدّة هناك لا يكون أي نموذج مُعدًا ويفشل التوليد.

للحصول على إعدادات كاملة لمزودات الخدمة، وتوليد الصور/الفيديو، وتحويل النص إلى كلام (TTS)، والتعرف على الكلام (ASR)، وتحليل المستندات، والبحث عبر الإنترنت، والتحكم في الوصول، وعلامات الميزات، راجع [تعليمات الإعداد](./configuration.mdx).

## التشغيل

تُحفظ الدروس في PostgreSQL، ويرفض الخادم البدء بدون `DATABASE_URL`. ابدأ قاعدة بيانات تطوير محلية (PostgreSQL منفصل في Docker على `127.0.0.1:5432`، مشترك بين كل النسخ على هذا الجهاز؛ استخدم `OPENMAIC_DB_PORT` لمنفذ آخر) واضبط `DATABASE_URL` في `.env.local`:

```bash
pnpm db:up
```

```bash title=".env.local"
DATABASE_URL=postgres://openmaic:openmaic-dev@127.0.0.1:5432/openmaic
```

شغّل خادم التطوير:

```bash
pnpm dev
```

افتح [http://localhost:3000](http://localhost:3000)، وسترى منشئ الدروس في OpenMAIC. أدخل موضوعًا أو ارفع مواد تعليمية، ثم اضغط على "Generate". سيقوم المعلم الذكي ببناء درس كامل متعدد المشاهد. تعتمد صيغ المواد المدعومة على المحلل المختار، وتشمل عادةً PDF، ومستندات Office، وMarkdown/نص عادي، وصور، وبعض ملفات الصوت/الفيديو؛ ويعتمد ذلك على دعم المحلل.

## تصدير الفصل

بعد اكتمال توليد الفصل ووسائطه، يفتح زر التنزيل في أعلى الفصل قائمة التصدير:

- **تصدير PPTX**: شرائح قابلة للتحرير. يُبقي خيار **مع شرائح بديلة (موصى به)** المشاهد التفاعلية والاختبارات ومشاهد التعلم القائم على المشاريع في أماكنها من الدرس، فيصبح كل منها شريحة فيها زر **فتح عبر الإنترنت** ورمز QR يفتحان المشهد في الفصل عبر الإنترنت. أما **الشرائح فقط** فيستبعد هذه المشاهد.
- **تصدير حزمة الموارد**: خيار PPTX نفسه، مع كل مشهد تفاعلي صفحةَ ويب مستقلة.
- **تصدير بتنسيق HTML**: ملف واحد مستقل يشغّل الفصل دون اتصال بالشبكة، مع التعليق الصوتي والترجمة النصية، والإضاءة المركّزة ومؤشر الليزر، وفيديو الشرائح، وبطاقات النقاش، والمشاهد التفاعلية. تنتظر مشاهد الاختبارات والمشاهد التفاعلية ومشاهد المشاريع حتى ينتقل المتعلم. لا يتضمن مشهد التعلم القائم على المشاريع إلا موجز المشروع (الهدف والمراحل)، ومتابعة المشروع تحتاج إلى الفصل عبر الإنترنت واتصال بالشبكة. وإذا أبلغ التصدير عن موارد تعذّر تضمينها، فلن تظهر تلك الأجزاء من المشاهد التفاعلية في ملف HTML غير المتصل، لكنها تظل متاحة في الفصل عبر الإنترنت. خيار **مع التعليق الصوتي والفيديو** يُشغَّل كما في الفصل؛ وخيار **بلا تعليق صوتي** ينتج ملفًا أصغر تتقدم فيه الترجمة النصية بحسب وقت القراءة ولا يتضمن الفيديو.
- **تصدير ملف الفصل ZIP**: بنية المقرر ووسائطه، لنسخه احتياطيًا أو استيراده في نشر آخر لـ OpenMAIC.

إذا كان الفصل سيتجاوز 400 ميغابايت في ملف HTML واحد، فإنه يُحفظ بدلًا من ذلك ملفَّ ZIP: فك ضغط الملف كاملًا ثم افتح `classroom.html`، مع إبقاء المجلدات `audio/` و`media/` و`images/` بجانبه.

يحتاج ملف HTML المُصدَّر إلى متصفح ويب يدعم JavaScript. على الهاتف، افتحه في متصفح مثل Safari أو Chrome: فهو لا يعمل على iPhone داخل WeChat أو في معاينة تطبيق «الملفات».

```bash
pnpm build
DATABASE_URL=postgres://... pnpm start
```
