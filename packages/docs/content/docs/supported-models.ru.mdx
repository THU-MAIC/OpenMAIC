На этой странице перечислены провайдеры и модели, встроенные в открытую версию OpenMAIC. В [`openmaic.yml`](./configuration.mdx) провайдер указывает один из них как свой `preset`, а настройки моделей в веб-приложении предлагают тот же каталог. Доступность также зависит от аккаунта провайдера, региона и конфигурации сервера, а список `models` провайдера может сузить выбор в настройках моделей.

## Пресеты

Пресет — встроенный шаблон провайдера: какой вендор, какой адрес и какие возможности покрывает одна учётная запись. Каждый провайдер в `openmaic.yml` или в настройках моделей указывает пресет.

**Пресеты одной возможности** используют id провайдеров из таблиц ниже, по одному на возможность: `openai` — это чат OpenAI, а изображения, синтез и распознавание речи OpenAI — `openai-image`, `openai-tts` и `openai-whisper`. Три id отличаются от id реестра, потому что его уже занимает другой пресет: веб-поиск MiniMax — `minimax-search`, веб-поиск Doubao — `doubao-search`, генерация изображений Lemonade — `lemonade-image`.

**Пресеты Token Plan** покрывают несколько возможностей одним ключом, каждую — по собственному адресу тарифа. Когда мастер первого запуска подключает такой пресет, он также заполняет слоты, для которых тариф рекомендует модели.

| Пресет | Тариф | Покрывает |
| --- | --- | --- |
| `minimax` | MiniMax | Чат, изображения, видео, TTS, веб-поиск |
| `tokendance` | TokenDance | Чат, изображения, видео, TTS, веб-поиск |
| `volcengine-ark` | Volcengine Ark Agent Plan | Чат, изображения, видео, TTS, веб-поиск |
| `kimi-coding-plan` | Kimi coding plan | Чат |

`openai-compatible` подключает любой OpenAI-совместимый чат-сервер: ему нужен `baseUrl`, а настройки моделей предлагают его список `models`.
