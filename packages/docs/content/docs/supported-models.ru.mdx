На этой странице перечислены провайдеры и модели, встроенные в открытую версию OpenMAIC. В [`openmaic.yml`](./configuration.mdx) провайдер указывает один из них как свой `preset`, а настройки моделей в веб-приложении предлагают тот же каталог. Доступность также зависит от аккаунта провайдера, региона и конфигурации сервера, а список `models` провайдера может сузить выбор в настройках моделей.

## Пресеты

Пресет — встроенный шаблон провайдера: какой вендор, какой адрес и какие возможности покрывает одна учётная запись. Каждый провайдер в `openmaic.yml` или в настройках моделей указывает пресет.

**Пресеты одной возможности** используют id провайдеров из таблиц ниже, по одному на возможность: `openai` — это чат OpenAI, а изображения, синтез и распознавание речи OpenAI — `openai-image`, `openai-tts` и `openai-whisper`. Три id отличаются от id реестра, потому что его уже занимает другой пресет: веб-поиск MiniMax — `minimax-search`, веб-поиск Doubao — `doubao-search`, генерация изображений Lemonade — `lemonade-image`.

**Пресеты Token Plan** покрывают несколько возможностей одним ключом, каждую — по собственному адресу тарифа. Подключение такого пресета в **Настройки → Token Plan** также заполняет ещё не назначенные слоты, для которых тариф рекомендует модели.

| Пресет | Тариф | Покрывает |
| --- | --- | --- |
| `minimax` | MiniMax | Чат, изображения, видео, TTS, веб-поиск |
| `tokendance` | TokenDance | Чат, изображения, видео, TTS, веб-поиск |
| `volcengine-ark` | Volcengine Ark Agent Plan | Чат, изображения, видео, TTS, веб-поиск |
| `kimi-coding-plan` | Kimi coding plan | Чат, веб-поиск, загрузка веб-страниц |

Подключение Kimi Coding Plan в **Настройки → Token Plan** рекомендует чат, веб-поиск и загрузку веб-страниц с общим ключом тарифа и адресом `https://api.kimi.com/coding/v1`. Если загрузка использует только неявный встроенный ридер по умолчанию, подключение сразу назначает Kimi без подтверждения конфликта, даже при сохранении текущих настроек. Явные назначения рабочего пространства (включая `null`), а также невстроенный ридер или `null`, заданные развёртыванием, обрабатываются через существующий выбор при конфликте. Отключение удаляет назначения тарифа и восстанавливает серверное значение по умолчанию (встроенный ридер, если другой не настроен), но не прежний явный выбор рабочего пространства. Закреплённые слоты не меняются. Тарифы, не объявляющие загрузку веб-страниц, не меняют этот слот.

Мастер первого запуска оставляет загрузку веб-страниц на встроенном ридере; рекомендация тарифа для загрузки применяется только при подключении через страницу настроек Token Plan.

`openai-compatible` подключает любой OpenAI-совместимый чат-сервер: ему нужен `baseUrl`, а настройки моделей предлагают его список `models`.

### Веб-поиск и загрузка DeepSeek

Пресет `deepseek` использует общие `DEEPSEEK_API_KEY` и базовый URL API для чата, веб-поиска и размещённого извлечения Markdown. Поиск вызывает `POST /v1/tools/search`, возвращает до 50 результатов и обрезает запрос до 128 кодовых точек Unicode. Текст берётся из `summary`, а при его отсутствии — из `snippet`. Загрузка вызывает `POST /v1/tools/fetch` и читает `content` и необязательный непустой `title`.

В старой конфигурации включите `WEB_SEARCH_DEEPSEEK_ENABLED=true` или явно добавьте `web-search.deepseek` в `server-providers.yml`. Одни учётные данные чата не включают поиск и не заменяют текущий поисковый сервис по умолчанию. `WEB_SEARCH_DEEPSEEK_ENABLED=false` принудительно отключает поиск. При наличии `openmaic.yml` старая переменная не назначает слот: явно объявите провайдера и назначьте `webSearch` и/или `webFetch`.

The default API base is `https://api.deepseek.com/v1`. On `api.deepseek.com`, every base path (including `/beta`) is normalized to `/v1` before appending `/tools/search` or `/tools/fetch`. Custom gateway bases preserve their configured path prefix; a bare root gets `/v1` first. Custom endpoints belong in deployment configuration, while client and workspace overrides remain restricted to official endpoints. The default fetch reader remains `builtin`. See [DeepSeek official pricing](https://api-docs.deepseek.com/quick_start/pricing) for current request charges. Failed requests and searches with no results are not billed.

```yaml
providers:
  deepseek:
    preset: deepseek
    apiKey: ${DEEPSEEK_API_KEY}
    baseUrl: https://api.deepseek.com/v1
slots:
  webSearch: deepseek
  webFetch: deepseek
```

### Веб-поиск Kimi

Пресеты `kimi` (Moonshot Open Platform) и `kimi-coding-plan` используют один API-ключ и базовый URL для чата и веб-поиска. Назначьте `webSearch` тому же провайдеру, что и чат: отдельный ключ или модель поиска не нужны.

Базовые URL Open Platform `https://api.moonshot.cn/v1` и `https://api.moonshot.ai/v1` используют `/tools/search_pro`. Текст результата собирается из фрагментов страницы; если их нет, используется краткое описание. Базовые URL coding plan `https://api.kimi.com/coding/v1` и `https://api.kimi.ai/coding/v1` используют `/search` с включённой загрузкой страниц. Предпочтение отдаётся тексту страницы, затем краткому описанию. Один запрос возвращает не более 20 результатов.

В старой конфигурации учётные данные чата сами по себе не включают поиск. Установите `WEB_SEARCH_KIMI_ENABLED=true` или явно добавьте запись `web-search.kimi` в `server-providers.yml`. В `openmaic.yml` явно назначьте слот `webSearch`. Мастер настройки рекомендует поиск только для аккаунтов с официальным базовым URL.

Эндпоинт выбирается по пути базового URL: после удаления завершающих косых черт путь, оканчивающийся на `/coding/v1`, использует `/search`; все остальные используют `/tools/search_pro`. Пользовательские прокси, настроенные в `openmaic.yml`, должны сохранять эту структуру пути.

Если есть `openmaic.yml`, объявите `providers.<id>: { preset: kimi }` и задайте `slots.webSearch: <id>`: переменная старой конфигурации `WEB_SEARCH_KIMI_ENABLED` не назначает этот слот.

## Загрузка веб-страниц

По умолчанию слот `webFetch` использует `builtin` без ключа (Readability и Turndown; PDF по-прежнему используют `document`). `kimi` и `kimi-coding-plan` повторно используют ключ и базовый URL API своего провайдера для размещённого извлечения. Moonshot Open Platform использует `/tools/fetch`, Coding Plan — `/fetch`. `firecrawl` использует собственный ключ Firecrawl (общий с веб-поиском Firecrawl) и вызывает `/v2/scrape`. Резервного сервиса нет. Выберите сервис в настройках сервисов моделей или моделей курса либо задайте `slots.webFetch` в `openmaic.yml`. Ключ Kimi общий с чатом. Все сервисы сохраняют локальные проверки сеанса и публичных адресов и возвращают недоверенные данные.

DeepSeek также предоставляет размещённое извлечение Markdown через пресет `deepseek` с ключом и базовым URL чата. Явно назначьте `webFetch`, как в примере выше. Используется `/v1/tools/fetch`, адрес шлюза из развёртывания сохраняется. Тайм-ауты и одна повторная попытка только при транспортной ошибке совпадают с Kimi; HTTP-ошибки и неверные ответы не повторяются.
