---
title: Локальная база знаний и RAG
description: Привязывайте генерацию занятий к PDF-материалам с помощью PostgreSQL и pgvector.
---

Локальная база знаний разбирает PDF, делит текст на фрагменты, строит embeddings через BGE-M3 и сохраняет их в PostgreSQL с pgvector. Перед генерацией можно проверить и выбрать фрагменты, разрешенные для модели.

## 1. Запустите PostgreSQL

```bash
docker compose up -d postgres
```

```bash title=".env.local"
DATABASE_URL=postgresql://openmaic:openmaic@localhost:5433/openmaic
KNOWLEDGE_WORKSPACE_ID=demo-default
```

Таблицы и HNSW-индекс создаются автоматически при первом использовании.

## 2. Запустите BGE-M3 embedding service

Нужен OpenAI-совместимый `/v1/embeddings`, возвращающий векторы размерности 1024.

```bash
vllm serve BAAI/bge-m3 \
  --runner pooling \
  --host 0.0.0.0 \
  --port 8200 \
  --max-model-len 4096
```

```bash title=".env.local"
BGE_EMBEDDING_BASE_URL=http://localhost:8200/v1
BGE_EMBEDDING_MODEL=BAAI/bge-m3
# BGE_EMBEDDING_API_KEY=
```

## 3. Загрузите материалы

Откройте **Material Knowledge Base** или `/knowledge-base`. Поддерживаются PDF до 50 МБ. Список показывает статус, число страниц, фрагментов и embedding-модель.

## 4. Параметры поиска

| Параметр | По умолчанию | Диапазон |
| --- | --- | --- |
| Top-K фрагментов | `6` | `1`–`20` |
| Минимальное сходство | `0%` | `0%`–`95%` |
| Лимит символов контекста | `12,000` | `2,000`–`30,000` |

## 5. Сгенерируйте занятие

1. Включите **Local Knowledge Base** на главной странице.
2. Введите запрос и запустите генерацию.
3. Проверьте найденные фрагменты и оценки сходства.
4. Выберите нужные фрагменты и продолжите.

Только подтвержденные фрагменты используются для планов, слайдов, тестов, интерактивных виджетов, действий преподавателя и PBL.
