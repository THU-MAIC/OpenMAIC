Движок профессиональных заданий — экспериментальный режим для практического обучения. Он превращает рабочую задачу в занятие с вводными слайдами, операционными упражнениями, схемами и игровыми испытаниями.

## Подходящие задания

Используйте режим для процессов с инструментами, оборудованием, материалами, изменением состояния, ограничениями безопасности, контролем качества и решениями GO/STOP. Теоретические темы автоматически возвращаются к обычным сценам OpenMAIC.

## Генерация занятия

1. Опишите конкретную рабочую задачу на главной странице.
2. Включите **Experimental · Vocational Task** под полем ввода.
3. При необходимости включите **Local Knowledge Base**.
4. Запустите генерацию.

## Структура

Для подходящих задач обычно создается 10–14 сцен:

| Категория | Обычно | Назначение |
| --- | --- | --- |
| Введение и объяснение | `2`–`4` | Цель, риски, стандарты и критерии решения. |
| Практика процедуры | `5`–`7` | Шаги, проверки, измерения и подтверждения. |
| Игровые задания | `2`–`4` | GO/STOP, порядок шагов, поиск рисков, диагностика. |

## Виджет procedural-skill

`procedural-skill` содержит задачу, инструменты, упорядоченные шаги, прогресс, обратную связь об ошибках, критерии завершения, полный сброс и действия преподавателя.

Виджет доступен только в профессиональном режиме. В обычном Interactive Mode случайный запрос такого типа преобразуется в схему процесса.

## Совместно с RAG

Для технического обучения включайте оба режима. Подтвержденные фрагменты материалов передаются в план, практические виджеты и действия преподавателя.
