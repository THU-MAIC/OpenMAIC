OpenMAIC 是一个 Next.js 应用，可以在自己的机器上运行。你需要至少配置一个 LLM provider：云端 provider 通常需要 API key；本地 Ollama 或 Lemonade 不需要 API key。

## 前置条件

- **Node.js** 22.19.0 或更高
- **pnpm** 10.28.0（如果没装，先 `npm install -g pnpm@10.28.0`）
- 至少配置一个 LLM provider；云端 provider 通常需要 API key，本地 Ollama 或 Lemonade 不需要 API key

## 安装

克隆仓库并安装依赖：

```bash
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
pnpm install
```

安装过程中会构建项目所需的 workspace 包，首次安装可能需要一些时间。

## 配置

复制示例环境文件，填入至少一个 LLM 提供方：

```bash
cp .env.example .env.local
```

然后配置一个模型。最简单的文件方式是在 `.env.local` 旁边放一个最小的 `openmaic.yml`，key 写在 `.env.local` 中：

```bash title=".env.local"
OPENAI_API_KEY=sk-...
```

```yaml title="openmaic.yml"
providers:
  openai:
    preset: openai
    apiKey: ${OPENAI_API_KEY}

slots:
  llm: openai:gpt-5.5
```

`openmaic.example.yml` 就是这个起点，另外附有已注释的可选服务商和槽位。不使用该文件时，旧版服务商变量仍然有效，前提是用 `DEFAULT_MODEL` 指定模型：

```bash title=".env.local"
ANTHROPIC_API_KEY=sk-ant-...
DEFAULT_MODEL=anthropic:claude-sonnet-4-6
```

两者都不想配置的话，启动应用后在 **设置 → 模型** 中使用 **Connect a service**（接入服务）。既没有 `openmaic.yml`、也没有 `DEFAULT_MODEL`、也没有在那里接入服务时，没有任何可用模型，生成会失败。

完整的 provider、图像/视频生成、TTS、ASR、文档解析、联网搜索、访问控制和 feature flag 配置见[配置说明](./configuration.mdx)。

## 运行

课程保存在 PostgreSQL 中，未设置 `DATABASE_URL` 时服务会拒绝启动。先启动本地开发数据库（Docker 中一个独立的 PostgreSQL，位于 `127.0.0.1:5432`，本机所有检出共用；可用 `OPENMAIC_DB_PORT` 换端口），并在 `.env.local` 中设置 `DATABASE_URL`：

```bash
pnpm db:up
```

```bash title=".env.local"
DATABASE_URL=postgres://openmaic:openmaic-dev@127.0.0.1:5432/openmaic
```

启动开发服务器：

```bash
pnpm dev
```

打开 [http://localhost:3000](http://localhost:3000)，应该能看到 OpenMAIC 的课堂生成器。输入一个主题或上传学习材料，点生成，AI 教师会搭建一场完整的多场景课堂。支持的材料格式取决于所选解析器，通常包括 PDF、Office 文档、Markdown/纯文本、图片和部分音视频；具体范围以解析器支持情况为准。

## 生产构建

```bash
pnpm build
DATABASE_URL=postgres://... pnpm start
```

或者部署到 Vercel、Docker、你自己的服务器上——见[部署指南](./deployment.mdx)。
