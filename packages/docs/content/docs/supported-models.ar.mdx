تسرد هذه الصفحة المزودين والنماذج المدمجة في نسخة OpenMAIC مفتوحة المصدر. في [`openmaic.yml`](./configuration.mdx) يسمّي المزود أحدها بوصفه `preset`، وتعرض إعدادات النماذج في تطبيق الويب الكتالوج نفسه. يعتمد التوفر أيضًا على حساب المزود والمنطقة وإعدادات الخادم، ويمكن لقائمة `models` الخاصة بالمزود أن تضيّق ما تعرضه إعدادات النماذج.

## الإعدادات المسبقة

الإعداد المسبق (preset) قالب مزود مدمج: أي مورّد، وأي عنوان، وأي قدرات يغطيها حساب واحد. كل مزود في `openmaic.yml` أو في إعدادات النماذج يسمّي إعدادًا مسبقًا.

**الإعدادات المسبقة ذات القدرة الواحدة** تستخدم معرّفات المزودين في الجداول أدناه، واحدًا لكل قدرة: `openai` هو محادثة OpenAI، أما صور OpenAI وتحويل النص إلى كلام والتفريغ الصوتي فهي `openai-image` و`openai-tts` و`openai-whisper`. تختلف ثلاثة معرّفات عن معرّف السجل لأن إعدادًا مسبقًا آخر يستخدمه: بحث MiniMax على الويب هو `minimax-search`، وبحث Doubao على الويب هو `doubao-search`، وتوليد صور Lemonade هو `lemonade-image`.

**إعدادات Token Plan المسبقة** تغطي عدة قدرات بمفتاح واحد، كل منها على عنوان الخطة الخاص. ربط أحدها في **الإعدادات ← Token Plan** يملأ أيضًا الخانات التي توصي الخطة بنماذج لها ولم تُعيّن بعد.

| الإعداد المسبق | الخطة | يغطي |
| --- | --- | --- |
| `minimax` | MiniMax | المحادثة والصور والفيديو وTTS والبحث على الويب |
| `tokendance` | TokenDance | المحادثة والصور والفيديو وTTS والبحث على الويب |
| `volcengine-ark` | Volcengine Ark Agent Plan | المحادثة والصور والفيديو وTTS والبحث على الويب |
| `kimi-coding-plan` | Kimi coding plan | المحادثة |

يربط `openai-compatible` أي خادم محادثة متوافق مع OpenAI: يحتاج إلى `baseUrl`، وتعرض إعدادات النماذج قائمة `models` الخاصة به.

جميع معرّفات الإعدادات المسبقة:

| القدرة | الإعدادات المسبقة |
| --- | --- |
| المحادثة | `openai` و`azure` و`atlascloud` و`anthropic` و`bedrock` و`google` و`glm` و`qwen` و`deepseek` و`kimi` و`siliconflow` و`doubao` و`openrouter` و`grok` و`tencent-hunyuan` و`xiaomi` و`ollama` و`lemonade` و`openai-compatible`، وخطط Token Plan |
| TTS | `openai-tts` و`azure-tts` و`glm-tts` و`qwen-tts` و`minimax-tts` و`voxcpm-tts` و`doubao-tts` و`elevenlabs-tts` و`google-tts` و`browser-native-tts` و`lemonade-tts` |
| ASR | `openai-whisper` و`qwen-asr` و`azure-asr` و`browser-native` و`funasr-asr` و`lemonade-asr` |
| الصور | `seedream` و`openai-image` و`qwen-image` و`nano-banana` و`minimax-image` و`grok-image` و`comfyui-image` و`lemonade-image` و`openrouter-image` |
| الفيديو | `seedance` و`kling` و`veo` و`minimax-video` و`grok-video` و`happyhorse` و`openrouter-video` |
