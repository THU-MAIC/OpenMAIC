## Math typesetting

The platform loads deployment-hosted KaTeX only when math delimiters occur in page text outside scripts and styles. It then typesets that math and observes subsequent text changes. For dynamic math, include an initial formula in the page markup so the platform can detect that KaTeX is needed. Write math as LaTeX between `\(` and `\)` for inline math or `\[` and `\]` for display math, and leave typesetting to the platform. Do not load KaTeX, MathJax or any other math library yourself, and do not call their functions: the page can run where such a copy never loads, and a call into a missing library stops the page's script.
