# 对标研究：国际高质量课程的设计要素

> 对标范围（按用户选择）：国际公开课平台 + 名师讲解型内容
> 目标：把"高质量"拆成可模仿的结构决策，而不是形容词。

---

## 一、两类对标对象的差异

| | 国际公开课平台 | 名师讲解型内容 |
| --- | --- | --- |
| 代表 | MIT OCW、Coursera、edX、Khan Academy | 3Blue1Brown、Veritasium、MasterClass |
| 长度形态 | 6-15 分钟视频块，按周/单元组织 | 单集 10-25 分钟，或 2-5 分钟小课串联 |
| 强项 | 结构、目标对齐、评估闭环 | 演绎、注意力、可视化论证 |
| 弱项 | 演绎常平庸（教授对着 PPT 讲） | 缺评估、缺目标对齐、不可规模化 |
| 长课该借什么 | 骨架与评估 | 讲解的每一分钟 |

**结论：60 分钟长课要同时具备两者的强项——用公开课的骨架装名师内容的讲解。**

---

## 二、公开课平台的结构规律

### 2.1 模块化长度：6-15 分钟是稳定区间

- Coursera / edX 的课程大纲以"周"为单位，每周标注学时（如 "4 weeks · 2-3 hours/week"），单段视频普遍控制在 6-15 分钟。
- Khan Academy 单段 5-10 分钟，配合即时练习。
- MIT OCW 保留完整 50 分钟课堂录像，但**同时提供分段索引与配套习题**——它没有否认长视频，而是用索引和习题弥补长视频的注意力衰减。

**对 OpenMAIC 的含义**：60 分钟一次坐完是可行的，但**必须内部分段**。我们的模块层（7-17 分钟）+ 模块末检索点，正是把"50 分钟课堂"拆成可索引的单元。区别在于 MIT 靠人工索引，我们靠 `resetMinutes` 结构。

### 2.2 学习目标前置且可检验

公开课的每个模块都有 2-5 条 `learning objectives`，且动词是行为性的（explain / derive / apply / evaluate），不是"了解/掌握"。

**对 OpenMAIC 的含义**：`SceneOutline.teachingObjective` 字段已存在但未被强制填写。长课必须要求每个**模块**有目标（而不只是每页），且目标要用可检验动词。

### 2.3 评估与内容对齐

Coursera 的 in-video quiz 通常紧跟在被讲的概念之后（不是集中在周末），且题目直接检验刚才那段的目标动词。

**对 OpenMAIC 的含义**：检索点必须落在**模块末**（`plan.ts` 已实现），且 quiz 的 `questionTypes` 要与模块目标动词匹配（"derive" 的目标不能用单选题检验）。

### 2.4 平台普遍做不好的一件事

公开课的讲解质量方差极大。同一门课里，有的教授用 8 分钟把直觉建立起来，有的用 8 分钟念完 12 页 PPT。**平台的结构是标准化的，讲解不是。** 这正是名师型内容可以补的位置。

## 三、名师讲解型内容的五个可复用决策

### 3.1 3Blue1Brown：动画就是论证，不是配图

- 线性代数系列 16 集构成一条完整弧线，每集 10-25 分钟，**每集只推进一个观念**。
- 视觉不是"辅助说明"，而是推理的载体：矩阵乘法的动画本身就是"为什么这样乘"的证明。
- 有明确的"pause and ponder"时刻——主动制造认知停顿，而不是连续灌输。
- **零 bullet point**。页面上没有要点列表，只有正在被论证的对象。

**可复用**：单页只承载一个论证步骤；spotlight/laser 不是装饰，是"现在看这里，因为推理在这里发生"；长课必须有停顿点。

### 3.2 Veritasium：先让观众预测错

- 大量视频的开场是一个"你会怎么猜"的情境，然后给出反直觉结果，再解释。
- 这个结构把被动观看转成主动预测，是长视频留存最有效的手段之一。
- 错误预测被**明确说出来**（"most people think…"），而不是被默默否定。

**可复用**：模式 2（预测冲突）应成为长课每个模块至少用一次的结构；提示词已要求"state the intuitive-but-wrong expectation"。

### 3.3 MasterClass：示范优先，人格承载注意力

- 单节 2-5 分钟，几乎全部是"做给你看"，极少讲理论。
- 人格（名师本人的判断、犹豫、偏好）是留存的核心，不是知识本身。
- **完全没有评估**——这是它的短板，不是可借鉴项。

**可复用**：教师 agent 的 persona 在长课里权重更高（60 分钟靠人格维系注意力）；但评估必须自己补。

### 3.4 共性：分段（Segmenting）是唯一被反复验证的原则

Mayer 的多媒体学习原则里，与长课最直接相关的四条：

| 原则 | 含义 | 长课落地 |
| --- | --- | --- |
| **分段原则 Segmenting** | 学习者控制节奏的分段优于连续流 | 模块边界 = 天然分段点；`resetMinutes` |
| **信号原则 Signalling** | 高亮关键要素能降低外在负荷 | spotlight 必须先于对应讲解 |
| **冗余原则 Redundancy** | 同时呈现相同信息的图形+文字+旁白会损害学习 | 禁止"念页面上的文字" |
| **一致性原则 Coherence** | 无关素材（装饰图、背景音乐、花哨转场）降低学习 | 长课尤其要砍装饰 |

**这四条是评价体系里"认知负荷"维度的理论依据**（见 `04-评价体系.md`）。

### 3.5 一个反直觉的发现

名师内容普遍**比公开课慢**。3Blue1Brown 讲一个矩阵乘法可以花 12 分钟；公开课同内容 4 分钟讲完。慢的部分不是废话，是"把一步拆成三步并各自给理由"。

**对 OpenMAIC 的含义**：这直接支撑了 0.45 页/分钟（每页 2.2 分钟）的密度决策，而不是短课的 1-2 页/分钟。**长课的"信息密度"应该下降，"论证密度"应该上升。**

## 四、竞赛评分维度的参考价值

虽然本次不以竞赛为主对标，但其评分表对"评价体系"有校准作用——它们是**已经被专家共识过的维度清单**。

| 赛事 | 主要维度（定性） | 对评价体系的启示 |
| --- | --- | --- |
| 全国高校教师教学创新大赛 | 教学理念、教学内容、教学方法、教学评价、创新特色；材料含教学设计创新报告 + 课堂实录视频 + 教学大纲 | "课堂实录视频"这一项说明：**评审看的是真实 45-50 分钟课堂**，与我们的 60 分钟场景高度同构 |
| 全国职业院校技能大赛教学能力比赛 | 目标与学情、内容与策略、实施与成效、教学素养、特色创新 | "学情分析"被单列——长课必须体现对特定学习者的适配，不能通用化 |
| Reimagine Education Awards（Wharton/QS） | 教学交付创新、学习评估创新、学习成效证据 | 强调**成效证据链**：不只是设计好，要有可测量的学习结果 |

> 具体权重每年调整，落地前需核对当年官方通知，不在此固化数字。

**最有价值的一条**：教学能力比赛把"学情分析"单列，说明**同一份 60 分钟课对不同学习者应该不同**。这与 OpenMAIC 已有的 `userProfile`（`learnerProfileText()`）能力吻合，但当前提示词只把它当作背景描述，没有真正改变内容选择。

## 五、对标结论 → 设计决策映射

| 对标发现 | 落到 OpenMAIC 的具体决策 |
| --- | --- |
| 6-15 分钟分段是稳定区间 | 模块 7-17 分钟，60 分钟 5 个模块（`plan.ts`） |
| 公开课慢不下来 | 页密度降到 0.45 页/分钟，每页 2.2 分钟（`DEFAULT_SCENE_DENSITY`） |
| 名师内容论证密度高 | 单页五段骨架 + 演绎七模式（`03-知识点演绎规范.md`） |
| 检索紧跟概念 | 模块末 check（`rolesFor()` + 大纲规则 4） |
| 分段/信号/冗余/一致性 | 评价体系"认知负荷"维度的四条锚点 |
| 学情被单列 | 学科模板 + 学习者画像影响模块权重（待落地） |
| 成效证据链 | 评价体系必须含"可测量性"而非只有主观分（`04-评价体系.md` §4） |
