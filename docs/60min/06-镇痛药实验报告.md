# 镇痛药实验报告：用一份真人 60 分钟课做校准

> 实验对象：`C:\Users\lenovo\Desktop\药理学PPT\网页美化版\ch18镇痛药\index.html`
> 基线数据：`eval/long-form/scenarios/ch18-analgesics.json`
> 运行：`pnpm eval:long-form`（纯计算，不调模型，1 秒内完成）

---

## 一、为什么用这份 deck 做实验核心

这份 HTML 不是普通的 PPT 美化版。它的 `SPEAKER_NOTES` 里，每一页都带着设计者自己的：

| 字段 | 含义 | 对应长课模型的概念 |
| --- | --- | --- |
| `minutes` | 这一页讲几分钟 | `estimatedDuration` |
| `purpose` | 这一页的教学目的 | `teachingObjective` |
| `talk[]` | 讲稿提示（cue） | 讲稿 |
| `transition` | 交给下一页的那句话 | 页级 bridge |
| `section` | 章节标签 | 模块 |

**28 页、61.0 分钟、每页都有目的和过渡。** 这是一份真人真正讲过的 60 分钟课，而且是机器可读的。整个项目里没有第二份这样的东西——这就是它能当实验核心的原因。

实验要回答的问题不是"这份 deck 好不好"，而是：**我们给长课定的默认值，和真人讲一小时的实际做法差多少。**

## 二、基线数据

| 指标 | 值 |
| --- | --- |
| 页数 / 总时长 | 28 页 / 61 分钟 |
| 页密度 | **0.46 页/分钟** |
| 每页时长 | 均值 **2.18 分钟**，范围 1-4，变异系数 0.33 |
| 多页教学单元 | **7 个**，4-12 分钟，均值 7.3 |
| 单页小节 | 3 个（来源 / 体内过程 / 药理作用），是页级话题标签，不算单元 |
| 转场页（hero） | 4 页（封面、两个幕封、收束） |
| 每页教学目标 | **28/28** |
| 每页过渡句 | **28/28** |
| 讲稿提示字数 | 5,615 字 = **92 字/分钟** |
| 每页讲话段数 | 3.4 段 |

### 一个必须先说清的陷阱

**92 字/分钟不是语速，是 cue 密度。** 设计者写的是"定义抓三个成分：……"这样的提示，讲的时候会展开成两三句。如果把这 5,615 字直接喂给 TTS，按 240 字/分钟算，61 分钟的课只能产出 **28 分钟**。

这意味着：**备注 ≠ 讲稿**。真人写的是给自己看的提示，AI 要写的是学习者听到的每一个字。两者差 **2.2 倍**。这条如果不写进提示词，模型会照着 PPT 备注的密度写，生成出来的课只有目标时长的一半。

## 三、校准结果

| 指标 | 真人 | 模型 | 容差 | 判定 |
| --- | --- | --- | --- | --- |
| 每页分钟 | 2.18 | 2.10 | ±0.4 | ✅ |
| 总页数 | 28 | 29 | ±4 | ✅ |
| 模块数（多页单元） | 7 | 7 | ±1 | ✅ |
| 最长模块 | 12 | 10 | ±3 | ✅ |
| 最短模块 | 4 | 7 | ±3 | ✅ |
| 每页教学目标覆盖率 | 1.0 | 1.0 | ±0.2 | ✅ |
| 每页过渡句覆盖率 | 1.0 | 1.0 | ±0.2 | ✅ |
| 每分钟讲稿字数 | 92 | 204 | — | ℹ️ 口径不同 |
| 每页讲话段数 | 3.4 | 12.5 | — | ℹ️ 口径不同 |

### 三个结论

**1. 页密度是对的，而且是精确对的。**

`DEFAULT_SCENE_DENSITY = 0.45` 是上一轮凭设计推理定的，不是拟合出来的。真人给的是 0.459。模型 29 页 vs 真人 28 页，偏差 4%；每页 2.10 vs 2.18 分钟。

这不是巧合：短课的 1-2 页/分钟在 60 分钟尺度上必然崩，因为每页只剩 30-60 秒。**"每页更深而不是每页更多"这个判断被独立验证了。**

**2. 模块粒度原先偏粗，已修正。**

第一版按 `round(minutes / 11)` 切模块，60 分钟给 5 个模块（7/14/17/14/8 分钟），最长 17 分钟。

真人的实际做法是 **7 个多页单元，最长 12 分钟，均值 7.3 分钟**。

一个 17 分钟的模块，学习者无法把它当成"一个整体"记住——它会退化成"一段很长的时间"。改成 `round(minutes / 8.5)` 后，60 分钟给 7 个模块（7/9/10/8/8/10/8 分钟），与真人完全一致。

**3. 页级契约是缺的，已补上。**

真人 28 页**每一页**都有 `purpose` 和 `transition`。模型侧原来只有模块级 bridge，`teachingObjective` 是可选字段——等于把"每页为什么存在"和"下一页接什么"全交给模型即兴。

长课 brief 现在第 7、8 条是硬要求：

- 每页填 `teachingObjective`，动词必须可检验（derive / predict / distinguish / apply）
- 每页 `description` 以交棒句收尾，不只是模块边界

## 四、实验顺手抓到的两个真实缺陷

这两个不在原计划里，是在跑 25/60/90/240 分钟四个长度时暴露的。

### 缺陷 A：百分比权重不随长度收敛

`hook` 固定占 12%。60 分钟时是 7 分钟，没问题；**240 分钟时是 29 分钟**——一个四小时的课用半小时开场。`MAX_MODULE_MINUTES = 20` 这个常数定义了却从未被使用。

修法：`enforceMinimums` → `enforceBounds(parts, min, max)`，两端都夹住，盈余/亏空按余量重新分配。现在 240 分钟是 12 个模块 × 20 分钟，全部落在界内。

### 缺陷 B：close 和 check 抢同一个位置

原来 3 页的模块 + 有检索点 → `[open, close, check]`，一页开、一页收、一页测，**没有一页在讲课**。

修法：close 只在模块 ≥5 页时独立占位，否则并入 check。现在 4 页模块是 `[open, develop, develop, check]`。

### 附带修正：检索点密度

模块从 5 个变 7 个后，`CHECKPOINT_MODULE_MINUTES = 10` 只剩 2 个模块达标——60 分钟的课只有 2 个检索点。真人用了约 4 处口头检索。降到 9 分钟后，60 分钟得 3 个，61 分钟得 4 个，与真人一致。

同时加了保底：**任何长课至少有 1 个检索点**（25 分钟课原先一个都没有）。

## 七、局限

1. **单一样本。** 只有 ch18 一章。虽然结构与其余 16 章同源（同一批量生成手册、同一模板），但章节类型不同（药理机制章 vs 概论章）可能给出不同基线。建议至少再跑 ch02 药效学（概论型）和 ch17 解热镇痛抗炎药（同类对比章）。

2. **`retrievalPages` 是词表代理指标。** 靠"小测/提问/回忆"等词命中，不是真的 quiz 标记。这份 deck 本来就没有 quiz 页，所以代理指标够用；换成有 quiz 的课程要改。

3. **D3/D4/D5 未评分。** 演绎质量、认知负荷、参与度需要模型评审，本实验只覆盖了可纯计算的 D2/D6/D7。

4. **真人基线不是满分基线。** 这份 deck 的 D6 只有 3/5（全篇无 quiz 页，检索只靠口头提问），D2 只有 3/5（页时长变异系数 0.33）。校准的目的是"对齐真人的做法"，不是"对齐完美"——真人做得差的地方，模型不应该跟着差。
