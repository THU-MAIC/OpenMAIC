# 视频产出流水线（一次性构建记录）

> 产物：`镇痛药-60分钟.mp4`，1920×1080，25fps，60 分钟，H.264 + AAC。
> 本文记录把「60 分钟长课」落成 MP4 的完整方法。脚本本身是一次性构建工具，没有进仓库；这里留下的是可复现的参数和踩过的坑。

---

## 一、五个阶段

```
01 课程计划   18 页 / 7 模块 / 每页目标字数
02 正文生成   逐页调用模型 → 标题、要点、逐字稿
03 页面渲染   HTML 模板 → Edge 无头截图 → 1920×1080 PNG
04 配音       stepaudio-2.5-tts → 每页 MP3 → 实测时长
05 合成       每页「静图 + 缓慢推近 + 配音」→ 分段 → 拼接
```

---

## 二、三个实测常数（决定一切）

| 常数 | 实测值 | 用途 |
| --- | --- | --- |
| 中文讲课语速 | **252-262 字/分钟** | 由 18 页 15,537 字 → 60.5 分钟反推 |
| 页间静默 | 2.5 秒 | 前 0.6s 淡入 + 后 1.9s 淡出 |
| 静态图编码速度 | 60 秒片段 5.8 秒 | 决定总编码时间 |

**60 分钟 = 15,500 字旁白左右。** 这个数字比设计文档里的 12,240 字高，因为设计时假设 240 字/分 × 0.85 讲话密度，实测音色更快、更连续。

---

## 三、逐阶段参数

### 3.1 课程计划

页数不是先定的，是**反推**的：

```
目标字数 = 讲话秒数 × 语速
页数 = 目标字数 ÷ 模型自然产出长度
```

模型对「写 630 字」的要求会写 941 字（+49%）。与其反复退回（实测会卡死，2 分钟一页都落不了盘），不如按它的自然长度定页数：15,900 ÷ 880 ≈ **18 页**，每页 3.3 分钟。

**3.3 分钟一页是讲座节奏，不是视频节奏。** 每页配缓慢推近（zoompan 1.0→1.07）让画面不死。

### 3.2 正文生成

- **一页一次调用。** 一次写 3-5 页会让推理吃掉全部 16k token，`finish_reason: "length"`、正文 0 字、193 秒白跑。一页一次只用 2.5k token。
- **并发 3。** 串行 2.6 分钟/页 × 18 = 47 分钟；并发 3 压到约 15 分钟。
- **代价**：同模块内的页互相不知道对方在写什么，会出现近似重复的标题（实测有两组）。

### 3.3 页面渲染

```bash
msedge --headless=new --disable-gpu --no-sandbox --no-first-run \
  --hide-scrollbars --force-device-scale-factor=1 \
  --virtual-time-budget=2500 --disable-dev-shm-usage \
  --window-size=1920,1080 \
  --user-data-dir=<每页独立目录> \
  --screenshot=page.png file:///page.html
```

三个必须的坑：

1. **`--user-data-dir` 必须每页独立。** 复用同一个目录时，第二个实例会附着到第一个上，然后**静默忽略 `--screenshot`**：退出码 0，没有文件。
2. **`--virtual-time-budget=2500`** 让渲染在截图前完成，否则偶发空白。
3. **必须校验产物**（存在且 > 10KB），不能信退出码。实测约 1/3 的页第一次不出图，重试一次即可。

### 3.4 配音

```
POST https://api.stepfun.com/step_plan/v1/audio/speech
{ "model": "stepaudio-2.5-tts", "input": "...", "voice": "cixingnansheng",
  "instruction": "大学课堂讲授。语速适中偏慢，吐字清晰，句末下沉。专业术语按中文药理学读法念准，不要念成英文。段落之间自然停顿。",
  "response_format": "mp3" }
```

- **单次 input 上限 1000 字。** 超过直接 400。按句号切块（每块 ≤900 字），分别合成后用 ffmpeg concat 拼接。
- 18 页里 3 页超过 1000 字（1076-1099），必须切块。
- 实测每页 166-194 秒。

### 3.5 合成

每页一段：

```bash
ffmpeg -y -loop 1 -i page.png -i page.mp3 \
  -filter_complex "\
[0:v]scale=1920:1080,zoompan=z='min(zoom+0.00022,1.07)':d=<总帧数>:s=1920x1080:fps=25,\
format=yuv420p,fade=t=in:st=0:d=0.5,fade=t=out:st=<总时长-0.5>:d=0.5[v];\
[1:a]adelay=600|600,apad=whole_dur=<总时长>[a]" \
  -map "[v]" -map "[a]" -t <总时长> \
  -c:v libx264 -preset veryfast -crf 20 -pix_fmt yuv420p \
  -c:a aac -b:a 160k -ar 44100 -ac 2 seg.mp4
```

关键点：

- **`zoompan` 的 `d` 必须等于总帧数**，否则缩放不累积（`d=1` 每帧重置，画面完全静止）。
- 音频前置 600ms 静默（`adelay`），让配音在淡入之后开始。
- 每段首尾各 0.5 秒淡入淡出到黑，段间切换看起来像有意的转场。

拼接时**重新编码**而不是 `-c copy`：分段编码参数虽然一致，但 concat 后时间戳偶发漂移。

## 五、已知瑕疵

1. **要点文字偏短、个别断在半句**（如「呼吸抑制等下游边」少了两个字）。模型写 `keyPoints` 时贴着 20 字下限写。旁白完整，投影上看会显潦草。修法：给 `keyPoints` 单独的二次调用，或把下限提到 30 字。
2. **同模块内标题近似重复**（「合成五将的受体地图」/「合成五将的受体定位」）。并发 3 的代价。修法：模块内串行，模块间并发。
3. **静态图 + 推近，没有真正的动画。** 图表生长、公式组装都没有。要做到那样得走 Remotion 渲染，60 分钟视频的渲染时间是数小时量级。

## 六、复现需要的环境

| 依赖 | 版本/路径 |
| --- | --- |
| ffmpeg | 9.0.2（含 ffprobe） |
| Edge | 任意 Chromium 内核，支持 `--headless=new` |
| Node | 22+（原生 fetch、AbortSignal.timeout） |
| StepFun | `step-5-preview`（文本）+ `stepaudio-2.5-tts`（语音） |

**StepFun 的 TTS 音色要单独开通。** 这个 key 的 `/v1/audio/voices` 返回空列表，`step-tts-mini` + `cindy` 之类的组合全部 400；只有 `stepaudio-2.5-tts` + `cixingnansheng` 可用。
