## 一句话结论

**60 分钟不是把页数乘以四，而是四个结构性约束同时失效**：时长无人计算、场景密度按短课写、没有模块层、跨页记忆只有一页。

## 用法

用户需求里写明时长即可，无需额外参数：

```
做一个 60 分钟的中医基础理论课，面向大二学生
```

`detectLongForm()` 识别 ≥25 分钟为长课，`planForRequirement()` 生成预算，全链路自动切换。

## 关键数字（60 分钟 / 中文，已对真人基线校准）

- 7 个模块：7 / 9 / 10 / 8 / 8 / 10 / 8 分钟
- 29 页，平均 2.1 分钟/页（不是 60-120 页）
- 12,240 字旁白（240 字/分钟 × 60 分钟 × 0.85）
- 3 个模块末检索点（61 分钟课时为 4 个）
- 7 个注意力重置点：00:00 / 07:00 / 16:00 / 26:00 / 34:00 / 42:00 / 52:00

对照真人基线（ch18 镇痛药，28 页 / 61 分钟 / 2.18 分钟每页）：页数偏差 4%，模块数完全一致。

## 实验

```bash
pnpm experiment:long-form                 # 修订实验控制台 → http://localhost:8787
# Windows 也可双击仓库根目录的 start-long-form-experiment.cmd
pnpm eval:long-form                       # 跑校准，输出报告到 eval/long-form/reports/
pnpm parse:deck <deck目录> <输出.json>     # 把任意一章「网页美化版」转成基线数据
```

控制台用来验证审校与修复链路能不能用真实模型跑通（十一个检查点）；校准被 `tests/eval/long-form-calibration.test.ts` 锁住：默认值一旦漂离真人基线，测试直接失败。

## 下一步（未落地）

完整清单见 [08-未完成项与问题清单](./08-未完成项与问题清单.md)。最要紧的三条：

1. **用真实模型跑一次完整长课**：审校、修复、台账、审计四件事都只有纯逻辑测试，从未对真实模型验证过。这是当前最大的未知。
2. **场景级修订**：大纲层已多轮，讲稿层仍是"念页/宣告"一次成型。29 页 × 2 的成本要先测收益。
3. **扩充基线样本**：再跑 ch02 药效学（概论型）与 ch17 解热镇痛抗炎药（同类对比章），确认 7 模块粒度不是单章巧合。

其余：两遍式大纲（>120 分钟）、并行生成默认值、契约的语义自动验证、视频渲染分段、学科模板、审校用独立强模型。
